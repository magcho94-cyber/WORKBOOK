# 종로M 영어 워크북 제작기

영어 지문을 문장별로 입력하면 OpenAI가 문장 해석, 내용 확인, O/X, 빈칸, 어법, 문장 연결 근거의 **검토 가능한 초안**을 작성합니다. 검토 후 학생용·교사용 PDF를 한 번에 출력합니다.

## 시작하기

Python 3.10 이상이 필요합니다. 압축을 푼 디렉터리에서 실행하세요.

```bash
python -m pip install -r requirements.txt
```

macOS / Linux:

```bash
export OPENAI_API_KEY="본인의_API_키"
python app.py
```

Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="본인의_API_키"
python app.py
```

브라우저에서 `http://127.0.0.1:8765`를 여세요. API 키가 없어도 **예시 초안 불러오기**와 **삽화 없이 시험 출력**은 가능합니다. 키는 화면에 입력하지 않고 로컬 서버의 환경 변수로만 전달합니다. 생성한 내용과 PDF는 `output/`에도 저장됩니다.

설치 전에는 `sample_output/`의 예시 학생용·교사용 PDF로 출력 형태를 먼저 확인할 수 있습니다. 예시 학생용 PDF의 READING 페이지에는 해당 문장에 맞춘 만화 삽화가 들어 있습니다.

## 입력 형식과 작업 순서

1. 영어 **한 문장에 한 줄**을 사용합니다. 빈 줄은 문단 구분, `# 제목`은 문단 첫 줄의 소제목입니다. 한국어 번역은 동일한 문장 순서로 넣거나 생략합니다. 자동 문장 분리는 하지 않습니다. `Mr.`, 인용부호 등에서 원문이 잘리는 문제를 막기 위한 형식입니다.
2. **OpenAI로 초안 생성**을 누릅니다. 각 문단마다 API를 호출하며, 문단이 길면 시간이 걸립니다. 문장 원문은 입력값을 그대로 복사하고 문장 수가 맞지 않으면 생성이 중단됩니다.
3. JSON에서 번역, 주제·제목, 문항 정답과 근거, 어법 오답의 타당성을 반드시 검토합니다. 특히 AI가 만든 O/X와 어법 오답은 교사가 확인해야 합니다. **초안 JSON 저장/불러오기**를 지원합니다.
4. **삽화 포함 워크북 자동 생성·다운로드**를 누릅니다. READING 페이지의 영어 2~3문장마다 애니메이션풍 삽화 한 장을 자동 생성하여 해당 페이지에 배치한 뒤 PDF를 만듭니다. 화면에 이미지 생성 진행 상황이 표시됩니다. 이미지 생성은 별도의 API 사용량과 시간이 듭니다. 실패 후 재시도하면 이미 만들어진 그림은 재사용합니다.
5. 다운로드되는 ZIP에는 학생용·교사용 PDF 두 개, 검토한 JSON, 문장 수 검증 기록이 들어갑니다. API 키 없이 출력만 시험하려면 **삽화 없이 시험 출력**에 체크하세요.

## 워크북 구성

| 부분 | 학생용 | 교사용 |
| --- | --- | --- |
| READING | 영어 원문·해석·필기 여백, 문단 끝 주제·제목 작성 | 문단 주제·제목과 전체 해석 |
| STEP 1 | 모든 문장 해석, 문장 간 논리 관계 빈칸, 한국어 내용 확인과 O/X | 전체 해석, 문장 연결 이유, 내용/OX 정답 |
| STEP 2 | 모든 문장에 단어 빈칸 2~3개 | 빈칸 정답 |
| STEP 3 | 모든 문장 어법 선택, 근거 작성 두 줄 | 어법 정답과 근거 |
| STEP 4 | 전체 문단 순서 배열 (문단 하나일 때는 해당 문단을 연속 부분으로 분할) | 배열 정답 |
| STEP 5 | 문단별 전체 문장 순서 배열 | 배열 정답 |

PDF 생성 직전에 단계별 문장 ID를 원문과 대조합니다. 원문 영어는 AI의 출력으로 대체하지 않습니다. READING은 문단별로 2~3문장씩 한 페이지에 배치하며 각 페이지에 해당 문장 기반 삽화를 넣습니다. 문단 자체가 한 문장인 경우에는 한 문장짜리 페이지가 됩니다. 제공된 종로M 로고와 한글 글꼴이 포함되어 있습니다.

## 운영 메모

- 본 프로그램은 **로컬 브라우저 앱**으로 `127.0.0.1`에만 연결됩니다. 생성 요청을 하면 본문이 OpenAI API에 전송됩니다.
- 텍스트 모델 기본값은 `gpt-5-mini`입니다. 화면에서 바꿀 수 있습니다. 이미지 모델은 환경 변수 `OPENAI_IMAGE_MODEL`로 바꿀 수 있으며 기본값은 `gpt-image-1-mini`입니다.
- API 사용량과 과금은 사용하는 키의 계정에 적용됩니다. 원문의 문장 수가 많을수록 문단별 요청과 삽화 수가 늘어납니다.
- JSON 필드를 임의로 삭제하거나 영어 원문과 어법 정답을 서로 맞지 않게 고치면 검증 오류를 반환합니다. 먼저 JSON을 수정하세요.
- 학교 배포 전 개인정보가 포함된 원문이 없는지 확인하세요. 보안이 필요한 배포형 서비스로 전환할 경우 사용자 인증·비밀키 저장·비용 한도·작업 대기열을 추가해야 합니다.

개발 테스트를 실행하려면 `python -m pip install -r requirements-dev.txt` 후 `python -m unittest -v test_workbook`을 사용하세요.
